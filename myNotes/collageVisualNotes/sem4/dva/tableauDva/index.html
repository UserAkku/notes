Module_01 · Introduction
TABLEAU KYA HAI?
Visual Analytics Platform // Founded 2003

Tableau ek Visual Analytics Platform hai — yani aap data ko visually dekh sakte ho bina koi coding likhe. Bas drag aur drop karo, Tableau khud hi background mein SQL queries run karta hai aur data fetch karta hai.

2003 mein found hua tha, aur 2019 mein Salesforce ne ise khareeda. Aaj kal almost har badi company mein Tableau use hota hai — chahe wo small startup ho ya Fortune 500 company.

⚡ Sabse Important Baat
Tableau mein koi bhi programming language nahi chahiye. Ek data analyst, data scientist, ya fresher — sab log iska use kar sakte hain. Sirf samajhna hai ki data ko kaise arrange karein.

✦ Advantages

  • A1
    Drag & Drop
    Koi coding nahi — bas value ko kheench ke daalo, chart ban jaata hai
  • A2
    Quick Calculations
    Complex formulas ke liye built-in shortcuts hain — ek click mein running total, % of total, etc.
  • A3
    Interactive Dashboards
    Multiple charts ek jagah, filters live kaam karte hain, click karo aur data drill ho jaata hai
  • A4
    Multiple Data Sources
    Excel, CSV, databases, cloud platforms — sab se connect ho sakta hai
  • A5
    Large Data Handling
    Crores of rows bhi efficiently handle karta hai
  • A6
    Windows & Mac Both
    Power BI ke unlike, Tableau dono OS par kaam karta hai

✦ Disadvantages

  • D1
    Mehanga Hai (Costly)
    Desktop version ka license dusre tools se zyada expensive hai
  • D2
    Limited Data Cleaning
    Power BI ke comparison mein Tableau mein data preprocessing kam hoti hai — pehle Excel ya Python se clean karo, phir import karo
💡 Use Cases
Finance, Marketing, Sales, Healthcare, E-commerce, Operations — literally har field mein Tableau use hota hai. Agar aapko data dikhana hai kisi ko, Tableau best option hai.

Module_02 · Versions
PUBLIC vs DESKTOP
Konsa use karein? // Student vs Professional

Tableau ke do main versions hain. Public — free aur students ke liye perfect. Desktop — paid aur professional use ke liye.

Feature Tableau Public Tableau Desktop
Cost ✓ BILKUL FREE ✗ Paid License (Expensive)
Data Sources Sirf 7 sources — Excel, CSV, PDF, Spatial, Statistics, etc. 50+ sources — Cloud, Databases (MySQL, Oracle), Data Warehouses, REST APIs
Data Rows Limit Maximum 1.5 Million rows (15 lakh) Unlimited rows
Saving Files Locally save kar sakte ho + Tableau Public community par upload kar sakte ho (Data public hoti hai!) Locally + Workspace mein securely share kar sakte ho
Data Privacy ✗ Koi privacy nahi — data public hoti hai ✓ Data secure rahti hai organization mein
Features Almost SAME features dono mein hain! Sirf upar ke differences hain.
🎯 Simple Rule
Student ho? → Tableau Public use karo. Free hai, saare features hain.
Working professional? → Company waali sensitive data ke liye → Tableau Desktop.
Company? → Big data, multiple sources, security chahiye → Tableau Desktop.

🔗 Types of Joins (Dono Tables ko Joinne ke Tarike)

⬛
Inner Join
Sirf Common Data
Dono tables mein jo matching rows hain, sirf wahi data aata hai. Agar koi row ek table mein hai par dusri mein nahi, toh nahi aayega.
◧
Left Join
Left ka pura + Right ka matching
Left table ka poora data aata hai, aur right table se sirf wo rows jo match karti hain. Example: Customers table (left) + Orders (right) → Jo customers ne order nahi kiya, woh bhi aayenge.
◨
Right Join
Right ka pura + Left ka matching
Right table ka poora data aata hai, left table se sirf matching. Example: Orders (right) — sirf woh customers jo order kar chuke hain.
⬜
Full Outer Join
Dono ka poora data
Dono tables ka poora poora data aata hai — chahe match ho ya na ho. Jo match nahi karta, wahan NULL values aati hain.
⬆️
Union
Tables ko stack karna (upar-neeche)
Jab same structure ke tables ko ek ke neeche ek combine karna ho — jaise 2014 ka data + 2015 ka data + 2016 ka data ek table mein.
🔗
Relationship (Default)
Tableau ka default Many-to-Many
Jab Data Source page par ek table doosri ke upar drop karo toh Relationship (Many-to-Many) automatically ban jaati hai. Highest data accuracy deta hai.
📌 Simple Rule — Join vs Union?
Join tab use karo jab dono tables mein ek common column ho (side-by-side merge karna ho).
Union tab use karo jab same type ka data alag alag tables mein ho (stack karna ho — jaise different years ka data).

Module_06 · Data
DATA TYPES IN TABLEAU
Common · Roles · Advanced

Har column ka ek data type hota hai — Tableau ko batata hai ki is column mein kis tarah ka data hai. Ye data type icon ke roop mein dikhta hai (Abc, #, calendar icon, globe icon).

Category 1: Common Data Types

Abc
Text (String)
Alphabets, symbols, alphanumeric characters. Jab bhi koi word ya sentence hoga.
Example: "Customer Name", "City", "Product ID"
📅
Date
Sirf date — koi time nahi. Calendar icon dikhta hai.
Example: Order Date, Ship Date (DD/MM/YYYY)
⏰
Date & Time
Date + Time dono saath. Seconds tak ka data hota hai.
Example: "2024-01-15 14:30:00"
#
Number
Koi bhi numeric value — whole number ya decimal dono.
Example: Sales = 1500.50, Quantity = 5
T/F
Boolean
Sirf 2 values — True/False, Yes/No, ya 1/0.
Example: "Returned?" → Yes/No
🌍
Geographic Role
Koi bhi location data — state, city, country, postal code. Globe icon dikhta hai. Maps banane ke liye zaroori.
Example: State, City, Country, Postal Code
🖼️
Image Role
Jab column mein image URLs hoin (web links).
Example: Product image URL
⚙️
Advanced Types
Groups, Bins, Sets — hum khud banate hain. Next section mein detail mein padha hai!
Cluster Group, Histogram Bin, Comparison Set
⚠️ Data Type Changing
Tableau kabhi kabhi wrong data type assign kar deta hai. Data Source page par icon par click karo → correct type select karo. Yeh bahut common problem hai — especially dates aur numbers ke saath.

Module_07 · Core Concept
MEASURES & DIMENSIONS
Blue = Dimension // Green = Measure // Chart ka DNA

Yeh Tableau ka sabse important concept hai. Ek baar yeh samajh lo, charts banaana bilkul easy ho jaayega.

DIM
Blue Color // Horizontal Line Se Upar
DIMENSION
Category wala data — jo kisi cheez ke baare mein batata hai. Iska sum ya average nahi nikalta.

📦 Examples: Customer Name, City, State, Category, Sub-Category, Segment, Product ID, Order Date

Dimension = "Kis cheez ke basis par?"
MEA
Green Color // Horizontal Line Se Neeche
MEASURE
Numeric data — jiska sum, average, min, max, count nikaal sakte ho. Yahi chart ki "height" hoti hai.

💰 Examples: Sales, Profit, Quantity, Discount, Revenue

Measure = "Kitna?"
💡 Chart Formula — Yaad Rakho
Measure BY Dimension = Ek complete chart!

🔹 Sales BY Segment → Consumer, Corporate, Home Office ka Sales dikhega
🔹 Profit BY Category → Furniture, Office Supplies, Technology ka Profit dikhega
🔹 Discount BY Region → Har region ka average discount dikhega

3 Dimensions × 4 Measures = 12 alag charts ban sakte hain sirf ek dataset se!
⚡ Shortcut to Identify
Left panel mein ek horizontal line hoti hai — uske upar = Dimensions (Blue), neeche = Measures (Green).
Note: Row ID bhi numeric hai par yeh Dimension hai — kyunki iska sum nikalna meaningless hoga. ID + Order ID type cheezein hamesha Dimensions hoti hain.

Module_08 · Visualization
CHARTS KE TYPES
Bar · Line · Pie · Map · Scatter · Heat Map · Tree Map · Bubble · Word Cloud
📊
Bar Chart
Kab Use Karein? → Categorical Comparison
Jab ek category ke different members ko compare karna ho. Measure ko Rows mein, Dimension ko Columns mein daalo.

Example: Segment-wise Sales (Consumer vs Corporate vs Home Office)
📈
Line Chart
Kab Use Karein? → Trend Over Time
Jab date/time ke saath koi value ka trend dekhna ho. Jaise hi Date drop karo — Tableau automatically line chart suggest karta hai.

Example: Monthly Sales 2014-2017, Revenue growth over years
🥧
Pie Chart
Kab Use Karein? → % Distribution
Jab percentage distribution dikhani ho — total mein kiska kitna share hai. Quick Table Calculation → "Percent of Total" use karo.

Example: Category-wise contribution to total Sales
🗺️
Map Visual
Kab Use Karein? → Geographic Analysis
Jab geographic location ke basis par data dikhana ho. State, City, Country drop karo — Tableau map ban deta hai. Color se intensity dikhao.

Important: Edit Location → correct country set karo
⚬⚬
Scatter Plot
Kab Use Karein? → Numeric vs Numeric
Jab do numeric values ke beech relationship dekhna ho. Continuous values ke liye best hai — categorical ke liye nahi.

Example: Sales vs Quantity, Profit vs Discount (outliers detect karo)
🟥
Heat Map
Kab Use Karein? → Correlation / 2D Comparison
Jab do dimensions ke beech ek measure ka pattern dekhna ho. Dark color = high value, Light color = low value.

Example: Sub-Category × Region → Sales (kaun sa combo best hai?)
🟫
Tree Map
Kab Use Karein? → Part-of-Whole (Size Based)
Rectangles/tiles jitne bade, utni badi value. Ek nazar mein proportions samajh aate hain.

Example: Category/Sub-Category wise Sales — Technology ka tile sabse bada hoga
🫧
Bubble Chart (Packed Bubbles)
Kab Use Karein? → Same as Tree Map, Circle Format
Tree map jaisa hi, par tiles ki jagah circles. Circle ka size value batata hai.

Color se category dikhao, Size se measure dikhao — multiple dimensions ek saath!
💬
Word Cloud
Kab Use Karein? → Frequency / Text Analysis
Jis word ki frequency zyada hogi, uska size bada dikhega. Text analysis mein popular.

Marks → Text mein daalo + Size mein Count daalo → Word Cloud ready!
🎨 Charts Customize Kaise Karein?
Marks Card mein Color, Size, Label, Detail, Tooltip — yahan koi bhi field drop karo aur chart aur informative ban jaata hai. Color mein Segment daalo → bar automatically segment-wise colored ho jaayegi.

Module_09 · Advanced
ADVANCED DATA TYPES
Groups · Bins · Sets
GROUPS — Data ke Custom Categories Banana

Groups ka use tab karte hain jab aap data ko khud se manually group karna chahte ho. Tableau automatically groups nahi banata — aapko select karke banana padta hai.

Kaise Banate Hain?

  • 1
    Scatter plot ya koi bhi chart banao
    Customer IDs ko drop karo
  • 2
    Drag karke kuch points select karo
    Jo aap group mein chahte ho
  • 3
    Right-click → "Create Group"
    Ek naya colored group ban jaayega
  • 4
    Edit Group se rename karo
    e.g., "High Sales", "Low Quantity", "VIP Customers"

Use Case (Example):

Real Example
Sales vs Quantity ka scatter plot banao. Jo customers ne zyada quantity buy ki par sales kam hai unko select karo → Group 1 banao "Quantity High".

Jo customers ne zyada sales diya hai unko → Group 2 "Sales High".

Ab is group ko kisi bhi chart mein filter ya dimension ki tarah use karo!
BINS — Histogram Banana (Frequency Distribution)

Bins se aap numeric data ko equal ranges mein divide karte ho aur count karte ho — kitne records ek range mein fall karte hain. Isse Histogram banta hai.

Simple Example
Profit ka data hai — kuch -6000, kuch +8400 tak.
Bins = 500 set karo → Tableau automatically groups banana: -7000 to -6500, -6500 to -6000 ... 8000 to 8500
Phir dekho: Kitne customers ka profit 0 to 500 ke beech hai? Kitne ka negative mein?

Kaise Banate Hain?

  • 1
    Profit field par Right-click karein
  • 2
    Create → Bins
  • 3
    Bin size set karo (e.g., 500 ya 250)
    Bin size chhota = zyada detail, bada = broad picture
  • 4
    New "Profit (bin)" column ban jaayega
  • 5
    Columns mein Bin daalo, Rows mein Count
    Histogram ready!
SETS — Data ke Inclusion/Exclusion Groups Banana

Sets aapko data ke custom groups banane dete hain aur phir unpar set operations (Union, Intersect, Except) lagane dete hain. Ek ek record ke liye "IN" ya "OUT" status hota hai.

Kaise Banate Hain?

  • 1
    Chart mein kuch points select karo
  • 2
    Right-click → Create Set
  • 3
    Name do (e.g., "Higher Sales")
  • 4
    Left panel mein Set ka icon aayega (⋈)
  • 5
    Set use karo → IN/OUT dikhega

Set Operations:

  • ∩
    Intersect (AND)
    Jo dono sets mein IN hai — Common data chahiye
  • ∪
    Union (OR)
    Dono sets ka poora data
  • −
    Except (NOT)
    Set 1 mein hai par Set 2 mein nahi — unique data
Example
Set 1: "Higher Sales" customers
Set 2: "Negative Profit" customers
Intersect → Jo customers dono mein hain (zyada sale diya par loss hua)

Module_10 · Calculations
CALCULATED FIELDS
Naye Columns Banana // Formulas Apply Karna

Jab aapko existing columns ke basis par ek naya column banana ho — ya koi formula apply karni ho — tab Calculated Fields use hote hain. Yahan SQL aur programming jaisi calculations without code possible hai!

Kaise Create Karein?
Sheet mein kisi bhi field par Right-click → "Create Calculated Field" ya ऊपर dropdown mein Analysis → Create Calculated Field

Example 1: Revenue Calculate Karna

// Revenue = Sales minus (Sales × Discount)
[Sales] - ([Sales] * [Discount])

Yeh calculation ek naya column "Revenue" banayega. Ab ise kisi bhi chart mein use kar sakte ho Sales ki jagah.

Example 2: Conditional Column (IF statement)

IF [Profit] > 0 THEN "Profit"
ELSEIF [Profit] = 0 THEN "Break Even"
ELSE "Loss"
END

Naya column "Profit Status" banayega — har order ke liye Profit/Loss/Break Even likhega.

Available Function Categories:

  • →
    String Functions
    UPPER(), LOWER(), LEN(), TRIM(), FIND(), LEFT(), RIGHT(), MID(), REPLACE(), CONTAINS()
  • →
    Number Functions
    ABS(), ROUND(), FLOOR(), CEILING(), POWER(), SQRT(), MOD()
  • →
    Date Functions
    TODAY(), NOW(), YEAR(), MONTH(), QUARTER(), DATEPART(), DATEDIFF()
  • →
    Logical Functions
    IF/THEN/ELSEIF/ELSE, CASE/WHEN, IIF(), AND, OR, NOT
  • →
    Table Calculations
    RUNNING_SUM(), RUNNING_AVG(), RANK(), INDEX(), WINDOW_AVG() — ek cell ke value dusri cells se compare karne ke liye
💡 Quick Shortcut — Quick Table Calculation
Kisi bhi measure par Right-click → "Quick Table Calculation" → Running Total, % of Total, Difference, % Difference, Moving Average — ek click mein ready!

Module_11 · Dynamic Control
PARAMETERS
User-Controlled Dynamic Values // Slider + Dropdown

Parameters ek aisi user-controlled variable hai jo chart ko dynamic banata hai. Koi user slider drag kare ya dropdown se kuch select kare — chart automatically update ho jaata hai.

Use Case 1 — Top N Filter

Top 5 products dikhane ke bajaye, aap ek slider banao jahan user khud decide kare kitne top products dekhne hain (Top 1 se Top 20 tak).

  • 1
    Parameter banao "Top N"
    Data Type: Integer, Range: 1–20, Step: 1
  • 2
    Product Name field Filter mein daalo
  • 3
    Filter → Top → By Field → "Top N" parameter select karo
  • 4
    Parameter ko Show karo
    Right-click → Show Parameter → Slider aayega

Use Case 2 — Dynamic Dimension Selector

Ek hi chart mein Category, Sub-Category, City, Country, Segment — user dropdown se choose kare!

  • 1
    Parameter banao (String, List type)
    Values: category, sub-category, city, country, segment
  • 2
    Calculated Field banao
    IF [Parameter] = "category" THEN [Category] ELSEIF … END
  • 3
    Is Calculated Field ko chart mein use karo
  • 4
    Parameter show karo → Dropdown aayega
    User select kare → Chart badal jaayega!

Module_12 · Presentation
DASHBOARD BANANA
Multiple Charts Ek Jagah // Tiled vs Floating

Dashboard matlab — multiple charts ko ek single view mein combine karna. Boss ko ya client ko jab present karna ho toh dashboard hi sabse impactful hota hai.

Dashboard Banana — Basic Process
1. Pehle saare individual sheets (charts) banao
2. Bottom mein "New Dashboard" par click karo
3. Left panel se sheets drag karke canvas par daalo
4. Size, layout, colors customize karo → Done!

TILED Layout

Tableau khud hi charts ko arrange karta hai — equal boxes mein. Beginners ke liye best — koi overlap nahi, sab clean.

Kab Use Karein?
Jab aap chahte ho ki sab charts properly aligned rahein aur aapko manually adjust nahi karna pade.

FLOATING Layout

Aap manually charts ko kahan bhi rakh sakte ho — koi bhi size, koi bhi position. Advanced control milta hai par zyada mehnat lagti hai.

Kab Use Karein?
Jab custom sized, overlapping, ya pixel-perfect layouts chahiye hon.

Dashboard Objects (Extra Elements):

  • →
    Text Object
    Title, description, ya koi bhi text add karo — font size, color set karo
  • →
    Image Object
    Company logo ya koi image add karo — URL se ya local file se
  • →
    Horizontal/Vertical Containers
    Charts ko organized layout mein rakhne ke liye
  • →
    Blank Objects
    Spacing ke liye empty space daalo
🎨 Dashboard Design Tips
Simple colors rakho — neon green ya bright background mat lagao. Data clearly visible hona chahiye, background pe zyada dhyan mat dao.

Labels readable rahein — X axis, Y axis, chart titles properly named hone chahiye. Viewer ko yeh nahi puchna chahiye "yeh kya hai?"

📄
Navigate to Sheet

Button click karo → automatically dusri sheet ya dashboard par redirect ho jaao. Presentation mein useful.
