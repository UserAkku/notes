Proposition Kya Hoti Hai?

📌 Definition

Proposition = ek aisi statement jo ya toh TRUE hogi ya FALSE hogi. Dono nahi ho sakti ek saath!

  • ✅ "2 + 3 = 5" → Proposition hai (TRUE)
  • ✅ "7 ek even number hai" → Proposition hai (FALSE)
  • ❌ "x + 1 = 3" → Proposition NAHI (x ka value nahi pata)
  • ❌ "Close the window!" → Command hai, proposition nahi
  • ❌ "What time is it?" → Question hai, proposition nahi

DPP ke Important Questions 📋

Q1. Yeh proposition hai ya nahi?

"Every even integer greater than 2 can be expressed as sum of two primes" (Goldbach's Conjecture)

✅ Haan, proposition hai! Chahe prove na hua ho, but iska ek definite truth value hai (T ya F). Proposition ke liye prove hona zaruri nahi, sirf TRUE ya FALSE hona chahiye.
Q2. p: Flu hai, q: Exam miss hua, r: Course pass. Express karo: p → ¬r
✅ "Agar flu hai, toh course pass nahi karoge" — seedha implication hai!
Q3. Truth table banao: (p→q) ∧ (¬q→¬p)

✅ B → (F ∧ I)
"Only if" matlab implication hai. B = borrow, F = faculty, I = valid ID

Quantifiers — Do Hote Hain

∀ — For ALL (Universal)

"Har ek ke liye sach hai"

∀x P(x) = P(x) sabke liye true hai

Disprove kaise? Ek bhi counterexample dhundho!

Example: ∀x (x² ≥ 0) over ℝ → TRUE ✅

∃ — There EXISTS (Existential)

"Kam se kam ek ke liye sach hai"

∃x P(x) = Koi ek x hai jiske liye P(x) true hai

Disprove kaise? Sabke liye false dikho!

Example: ∃x (x² = -1) over ℝ → FALSE ❌

Quantifiers ka Negation Very Important!

🔥 De Morgan's for Quantifiers
¬∀x P(x) ≡ ∃x ¬P(x)
¬∃x P(x) ≡ ∀x ¬P(x)

Rule: Negation andar push karo, quantifier flip karo (∀↔∃)

Example: ¬"All dogs are friendly" = ∃x (Dog(x) ∧ ¬Friendly(x)) = "Koi dog hai jo friendly nahi"

Nested Quantifiers — Order MATTERS!

⚠️ Yaad Rakh!

∀x ∃y P(x,y) ≠ ∃y ∀x P(x,y)

  • ∀x ∃y (x+y=0): Har x ke liye koi y hai (y = -x) → TRUE ✅
  • ∃y ∀x (x+y=0): Ek hi y sabke liye kaam kare → FALSE ❌ (impossible!)

Nested Negation

¬∀x ∃y P(x,y) ≡ ∃x ∀y ¬P(x,y)

Bas andar push karte jao, har quantifier flip karte jao!

DPP Q: Kya ∀x ∃y (x+y=0) over integers sach hai?
✅ TRUE! Har integer x ke liye, y = -x le sakte hain. Ye ek y provide karta hai har x ke liye.

Original: ∀x (IITM(x) → Hard(x))
Negation: ∃x (IITM(x) ∧ ¬Hard(x))
= "Koi ek IITM student hai jo hard nahi padhta"

CNF aur DNF

CNF (Conjunctive Normal Form)

AND of ORs

Har clause mein literals OR hote hain, phir sab clauses AND hote hain

Example: (p∨q) ∧ (¬p∨r) ∧ (q∨¬r)

Isko "Product of Sums" bhi kehte hain

DNF (Disjunctive Normal Form)

OR of ANDs

Har term mein literals AND hote hain, phir sab terms OR hote hain

Example: (p∧¬q) ∨ (¬p∧r)

Isko "Sum of Products" bhi kehte hain

CNF Convert Karne ke Steps Exam!

  1. → hatao: p → q ko ¬p ∨ q se replace karo
  2. ↔ hatao: p ↔ q ko (¬p∨q) ∧ (¬q∨p) se replace karo
  3. Negation andar push karo: De Morgan's use karo
  4. Distribute ∨ over ∧: (A ∨ (B ∧ C)) = (A ∨ B) ∧ (A ∨ C)
Convert to CNF: p → (q ∧ r)
Step 1: ¬p ∨ (q ∧ r) [eliminate →]
Step 2: (¬p ∨ q) ∧ (¬p ∨ r) [Distribute ∨ over ∧]
CNF: (¬p ∨ q) ∧ (¬p ∨ r) ✅
Convert to CNF: (p∧q) → r
Step 1: ¬(p∧q) ∨ r [eliminate →]
Step 2: (¬p∨¬q) ∨ r [De Morgan]
Step 3: ¬p∨¬q∨r [Associativity — already CNF!]
CNF: (¬p ∨ ¬q ∨ r) ✅ [Single clause!]

DPLL Algorithm Important!

SAT problem solve karne ka efficient algorithm:

  1. Unit Propagation: Agar kisi clause mein sirf ek literal hai (unit clause), use TRUE set karo
  2. Pure Literal Elimination: Agar koi literal sirf positive ya sirf negative form mein aata hai poore formula mein, use satisfy karo
  3. Branch/Split: Ek variable choose karo, pehle TRUE try karo, conflict pe backtrack karke FALSE try karo
  4. Base Cases: Empty clause set = SATISFIABLE | Empty clause (□) = CONFLICT, backtrack
DPLL: (p∨q) ∧ (¬p∨q) ∧ (¬p∨¬q) satisfiable hai?
Try p = T:
- (q) ∧ (¬T∨¬q) → (q) ∧ (¬q) — CONFLICT!
Backtrack. Try p = F:
- (F∨q) = (q) — Unit! q = T
- (¬F∨T) = T ✅
- (¬F∨¬T) = (T∨F) = T ✅
SATISFIABLE with p=F, q=T!

📜Proof StrategiesDPP 6

Proof ke Types — Sab Yaad Karo!

1. Direct Proof (Seedha Proof)

p → q prove karna hai, toh p assume karo aur q directly derive karo

Example: "If n is odd, then n² is odd"
n = 2k+1 (odd) → n² = 4k²+4k+1 = 2(2k²+2k)+1 → odd ✅

2. Contrapositive Proof

p → q prove karna hai → ¬q assume karo aur ¬p derive karo

Use karo jab seedha proof mushkil lage!
Example: "If n² is odd, then n is odd" → Prove: "If n is even, then n² is even"
n=2k → n²=4k²=2(2k²) → even ✅

3. Proof by Contradiction (Mathaparast Proof! 😄)

Prove P karna hai → ¬P assume karo → dono assumptions se contradiction nikalo

Classic example: √2 irrational prove karo
Assume √2 = a/b (lowest terms)
→ a² = 2b² → a even → a = 2k
→ 4k² = 2b² → b² = 2k² → b even
→ Contradiction! (a aur b dono even → lowest terms nahi tha)

4. Mathematical Induction (Seedhi Chain)

Step 1 (Base Case): P(1) ya P(0) true hai dikhao
Step 2 (Inductive Step): Assume P(k) true hai (Inductive Hypothesis), then prove P(k+1) is true
Conclusion: P(n) sabke liye true!

5. Proof by Cases

Saare possible cases alag-alag prove karo
Example: "n(n+1) always even" → Case 1: n even, Case 2: n odd — dono mein product even nikalta hai

Axiomatic System

Mathematics ka Game Analogy

Definitions = Game ke pieces
Axioms/Rules = Game ke rules
Proofs/Strategies = Game mein jeetnay ki strategy

Sirf definitions aur rules jaanna kaafi nahi — strategy chahiye!

Prove by contradiction: No largest prime number exists
Assume karo ek largest prime p₁, p₂, ..., pₙ hain.
Let N = (p₁ × p₂ × ... × pₙ) + 1
N in kisi bhi prime se divisible nahi (remainder 1 aata hai)
Toh ya toh N prime hai (larger than pₙ), ya koi aur prime factor hai — CONTRADICTION!
∴ Infinite primes hain ✅

Countable vs Uncountable

Countably Infinite

ℕ ke saath bijection (one-to-one correspondence) ho sakti hai

  • ℤ (integers) — countable!
  • ℚ (rationals) — countable!
  • Even numbers — countable!
  • Multiples of 7 — countable!
Uncountable

ℕ se bijection NAHI ho sakti

  • ℝ (reals) — uncountable!
  • (0,1) interval — uncountable!
  • Power set of ℕ — uncountable!

Cantor's Diagonalization — Brilliant Proof! Exam!

📌 ℝ uncountable hai — Proof

Assume karo (0,1) countable hai. Toh ek list ban sakti hai:
r₁ = 0.d₁₁ d₁₂ d₁₃ d₁₄ ...
r₂ = 0.d₂₁ d₂₂ d₂₃ d₂₄ ...
r₃ = 0.d₃₁ d₃₂ d₃₃ d₃₄ ...
...

Ab ek naya number r banao jisme:
r = 0.e₁ e₂ e₃ ... jahan eₙ ≠ dₙₙ (diagonal element se alag!)

Yeh r har rᵢ se alag hai (ith position pe different)!
Par r (0,1) mein hai — CONTRADICTION!
∴ (0,1) uncountable hai! ✅

Group ke 4 Axioms — ROTE KARO! Must!

📌 (G, *) ek Group hai agar...
  1. Closure (G1): a, b ∈ G → a*b ∈ G (result andar rahe)
  2. Associativity (G2): (a*b)*c = a*(b*c) (brackets kahi bhi lao)
  3. Identity (G3): ∃ e ∈ G such that e*a = a*e = a (koi neutral element)
  4. Inverses (G4): Har a ke liye ∃ a⁻¹ ∈ G such that a*a⁻¹ = e (undo karo)

+ Abelian group = ye sab PLUS commutativity (a*b = b*a)

LAGRANGE'S THEOREM Most Important!

🔥 Theorem of KINGS!
Agar G finite group hai aur H ≤ G (subgroup), toh |H| divides |G|

Corollaries (ye bhi exam mein aate hain):

  • Har element ka order |G| ko divide karta hai: ord(a) | |G|
  • Prime order wala group hamesha cyclic hota hai!
  • a^|G| = e for all a ∈ G (Fermat's little theorem ka group version!)
  • Possible subgroup orders = divisors of |G|

Example: |G| = 21, possible subgroup sizes = {1, 3, 7, 21}

Cyclic Groups

📌 Cyclic Group ⟨g⟩

G = ⟨g⟩ = {gⁿ : n ∈ ℤ} — ek single element se puri group generate ho

  • Har cyclic group Abelian hota hai
  • ℤₙ ke generators = elements coprime to n → φ(n) generators
  • gᵏ generator hai ↔ gcd(k, n) = 1
  • Finite cyclic group of order n ≅ ℤₙ
DPP Q: G has order 30. Koi element of order 8 ho sakta hai?

8 does NOT divide 30 → NO! Order 8 element exist nahi kar sakta!
Possible orders: divisors of 30 = {1, 2, 3, 5, 6, 10, 15, 30}

Ring kya hai?

📌 (R, +, ·) ek Ring hai agar...
  1. (R, +) Abelian group hai (identity = 0, inverses = -a)
  2. Multiplication associative hai: (a·b)·c = a·(b·c)
  3. Distributive laws: a·(b+c) = ab+ac AND (a+b)·c = ac+bc

Additional properties:
Commutative Ring = ab = ba bhi
Ring with Unity = 1 element hai (1·a = a·1 = a)

Characteristic of a Ring

📌 Characteristic

char(R) = smallest positive integer n such that n·1 = 0 (ya 0 if no such n)

  • char(ℤₙ) = n

Irreducible Polynomials Important!

📌 f(x) irreducible hai over F agar...
  • Degree 1: hamesha irreducible!
  • Degree 2 ya 3: F mein koi root (zero) nahi hona chahiye
  • Higher degree: difficult — Eisenstein's Criterion use karo

Key Fact: F[x]/⟨p(x)⟩ ek field hai ↔ p(x) irreducible hai over F!

x² + x + 1 over ℤ₂ mein irreducible hai?
Check roots in ℤ₂ = {0, 1}:
f(0) = 0+0+1 = 1 ≠ 0 ✅
f(1) = 1+1+1 = 3 ≡ 1 (mod 2) ≠ 0 ✅
Koi root nahi → Irreducible! ✅
ℤ₂[x]/⟨x²+x+1⟩ = GF(4) — 4 element field!

🤯 x²+1 ℝ mein irreducible hai

ℝ[x]/⟨x²+1⟩ ≅ ℂ!

α = x + ⟨x²+1⟩ ke liye, α² = -1 (kyunki x²+1=0 in quotient ring)

Isliye α = i behave karta hai! ℂ = {a + bi : a,b ∈ ℝ} ✅

RSA Algorithm — Step by Step Exam Type!

  1. Choose primes: p aur q choose karo (large primes)
  2. n = p × q
  3. φ(n) = (p−1)(q−1)
  4. e choose karo: 1 < e < φ(n), gcd(e, φ(n)) = 1
  5. d find karo: ed ≡ 1 (mod φ(n)) — Extended Euclidean se
  6. Public key: (e, n) | Private key: (d, n)
Encrypt: C = Mᵉ mod n | Decrypt: M = Cᵈ mod n
RSA: p=3, q=11, e=7. Encrypt M=4.
n = 3×11 = 33
φ(33) = (3-1)(11-1) = 20
Find d: 7d ≡ 1 (mod 20) → d = 3 (kyunki 7×3=21≡1)
Encrypt M=4: C = 4⁷ mod 33
4² = 16, 4⁴ = 256 mod 33 = 256-7×33 = 25, 4⁷ = 4⁴×4²×4 = 25×16×4 = 1600
1600 mod 33 = 1600-48×33 = 1600-1584 = C = 16

Discrete Logarithm Problem

🔐 Diffie-Hellman Key Exchange

Alice aur Bob publicly agree on prime p aur generator g
Alice: secret a, sends gᵃ mod p
Bob: secret b, sends gᵇ mod p
Shared secret: (gᵃ)ᵇ = gᵃᵇ mod p

Security: gᵃᵇ mod p se a ya b reverse calculate karna computationally infeasible = Discrete Log Problem!

Euler Paths & Circuits Exam!

Har EDGE exactly once use karo, same vertex pe return karo
