CNF aur DNF

CNF (Conjunctive Normal Form)

AND of ORs

Har clause mein literals OR hote hain, phir sab clauses AND hote hain

Example: (p∨q) ∧ (¬p∨r) ∧ (q∨¬r)

Isko "Product of Sums" bhi kehte hain

DNF (Disjunctive Normal Form)

OR of ANDs

Har term mein literals AND hote hain, phir sab terms OR hote hain

Example: (p∧¬q) ∨ (¬p∧r)

Isko "Sum of Products" bhi kehte hain

CNF Convert Karne ke Steps Exam!

  1. → hatao: p → q ko ¬p ∨ q se replace karo
  2. ↔ hatao: p ↔ q ko (¬p∨q) ∧ (¬q∨p) se replace karo
  3. Negation andar push karo: De Morgan's use karo
  4. Distribute ∨ over ∧: (A ∨ (B ∧ C)) = (A ∨ B) ∧ (A ∨ C)
Convert to CNF: p → (q ∧ r)
Step 1: ¬p ∨ (q ∧ r) [eliminate →]
Step 2: (¬p ∨ q) ∧ (¬p ∨ r) [Distribute ∨ over ∧]
CNF: (¬p ∨ q) ∧ (¬p ∨ r) ✅
Convert to CNF: (p∧q) → r
Step 1: ¬(p∧q) ∨ r [eliminate →]
Step 2: (¬p∨¬q) ∨ r [De Morgan]
Step 3: ¬p∨¬q∨r [Associativity — already CNF!]
CNF: (¬p ∨ ¬q ∨ r) ✅ [Single clause!]

DPLL Algorithm Important!

SAT problem solve karne ka efficient algorithm:

  1. Unit Propagation: Agar kisi clause mein sirf ek literal hai (unit clause), use TRUE set karo
  2. Pure Literal Elimination: Agar koi literal sirf positive ya sirf negative form mein aata hai poore formula mein, use satisfy karo
  3. Branch/Split: Ek variable choose karo, pehle TRUE try karo, conflict pe backtrack karke FALSE try karo
  4. Base Cases: Empty clause set = SATISFIABLE | Empty clause (□) = CONFLICT, backtrack
DPLL: (p∨q) ∧ (¬p∨q) ∧ (¬p∨¬q) satisfiable hai?
Try p = T:
- (q) ∧ (¬T∨¬q) → (q) ∧ (¬q) — CONFLICT!
Backtrack. Try p = F:
- (F∨q) = (q) — Unit! q = T
- (¬F∨T) = T ✅
- (¬F∨¬T) = (T∨F) = T ✅
SATISFIABLE with p=F, q=T!

📜Proof StrategiesDPP 6

Proof ke Types — Sab Yaad Karo!

1. Direct Proof (Seedha Proof)

p → q prove karna hai, toh p assume karo aur q directly derive karo

Example: "If n is odd, then n² is odd"
n = 2k+1 (odd) → n² = 4k²+4k+1 = 2(2k²+2k)+1 → odd ✅

2. Contrapositive Proof

p → q prove karna hai → ¬q assume karo aur ¬p derive karo

Use karo jab seedha proof mushkil lage!
Example: "If n² is odd, then n is odd" → Prove: "If n is even, then n² is even"
n=2k → n²=4k²=2(2k²) → even ✅

3. Proof by Contradiction (Mathaparast Proof! 😄)

Prove P karna hai → ¬P assume karo → dono assumptions se contradiction nikalo

Classic example: √2 irrational prove karo
Assume √2 = a/b (lowest terms)
→ a² = 2b² → a even → a = 2k
→ 4k² = 2b² → b² = 2k² → b even
→ Contradiction! (a aur b dono even → lowest terms nahi tha)

4. Mathematical Induction (Seedhi Chain)

Step 1 (Base Case): P(1) ya P(0) true hai dikhao
Step 2 (Inductive Step): Assume P(k) true hai (Inductive Hypothesis), then prove P(k+1) is true
Conclusion: P(n) sabke liye true!

5. Proof by Cases

Saare possible cases alag-alag prove karo
Example: "n(n+1) always even" → Case 1: n even, Case 2: n odd — dono mein product even nikalta hai

Axiomatic System

Mathematics ka Game Analogy

Definitions = Game ke pieces
Axioms/Rules = Game ke rules
Proofs/Strategies = Game mein jeetnay ki strategy

Sirf definitions aur rules jaanna kaafi nahi — strategy chahiye!

Prove by contradiction: No largest prime number exists
Assume karo ek largest prime p₁, p₂, ..., pₙ hain.
Let N = (p₁ × p₂ × ... × pₙ) + 1

∴ Infinite primes hain ✅

ℚ = {p/q : p ∈ ℤ, q ∈ ℕ, gcd(p,q)=1}

Include negatives: pair each positive with its negative → still countable
Include 0 → add it at start
∴ ℚ is countably infinite ✅

⚠️ Kal ke exam ke liye!
  1. Logic questions mein: Hamesha truth table ya equivalences se verify karo
  2. Proof mein: Har step pe justification likho (Premise, MP, MT, HS, etc.)
  3. Group Theory: Pehle check karo — closure, associativity, identity, inverses
  4. Lagrange: Order divisibility yaad rakhna — bahut help karta hai shortcuts mein
  5. Recurrences: Pehle homogeneous solve karo, phir particular guess karo
  6. Master Theorem: n^(log_b a) calculate karo, f(n) se compare karo
  7. Generating Functions: 1/(1-x) = Σxⁿ — ye starting point hai sab ka
  8. Graphs: Degree sum = 2|E| se start karo har problem mein
